# Ejercicio 04: una referencia no es un secreto

Construye una referencia sintética limitada a `Charge` y comprueba dos casos:
su uso antes de vencimiento con el propósito correcto y su uso con un propósito
distinto. No agregues una cadena que parezca tarjeta, cuenta o credencial.

La [solución](../../examples/04_token.rs) utiliza una referencia local sin
valor fuera del proceso de ejemplo.
