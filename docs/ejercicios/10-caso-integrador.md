# Ejercicio 10: seguir la evidencia

Ejecuta el flujo integrador y ubica qué módulo produjo cada campo del reporte.
Después cambia en una copia local la evidencia de conciliación por una
discrepancia y describe qué parte del flujo debe investigar una persona. La
[solución](../../examples/10_integration.rs) solo coordina componentes
sintéticos del curso.
