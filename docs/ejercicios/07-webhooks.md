# Ejercicio 07: el orden de llegada no es una garantía

Entrega primero un evento con secuencia 2 y luego uno con secuencia 1. Después
repite el primer identificador. Explica las diferencias entre `Stale` y
`Duplicate`. La [solución](../../examples/07_webhook.rs) trabaja enteramente
en memoria y no representa una firma de webhook.
