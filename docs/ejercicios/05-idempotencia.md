# Ejercicio 05: reintentar no es duplicar

Registra una llave sintética con `Accepted`; vuelve a usar la misma llave con
una propuesta distinta. Explica por qué el segundo resultado debe conservar el
primero. La [solución](../../examples/05_idempotency.rs) no representa una base
de datos ni una llamada a un proveedor.
